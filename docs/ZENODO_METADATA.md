## Description

Analysis code, frozen candidate and module registries, machine-readable results, decision records, and figure source data supporting a cross-tissue transcriptomic evaluation of an ECM–integrin–cytoskeletal programme in human fibroblast states. The release reuses public GEO and BioProject datasets and does not redistribute large third-party raw or processed objects. The highest defensible interpretation is an evidence-bounded mechanistic hypothesis with computational triangulation; the evidence grade remains CAUTION pending donor-replicated functional validation.
