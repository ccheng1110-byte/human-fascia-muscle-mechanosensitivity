# Release notes

## Version 1.0.0, 29 August 2026

- Initial public-ready reproducibility package.
- Includes analysis, audit, evidence-synthesis, and figure-generation scripts.
- Includes frozen candidate and module registries, machine-readable outputs, decision records, and final figure source data.
- Excludes third-party raw sequencing data, large processed RDS/Seurat objects, local Python/R caches, rendered manuscript review pages, and unpublished Word manuscript files.
- Replaces the original local project path with relative repository paths in the release copies of scripts and text records.

The release preserves the evidence boundary reported in the manuscript: computational triangulation supports an actomyosin-centred mechanotransduction-compatible programme, while the overall evidence grade remains CAUTION pending donor-replicated functional validation.
