# External data

This project is a secondary analysis of publicly available transcriptomic resources. No new primary sequencing data were generated.

Large third-party raw and processed objects are intentionally excluded from this release. The source accessions, analytical roles, and persistent repository links are listed in `public_accession_inventory.csv`. Acquisition and audit scripts are available under `../scripts/`.

Expected local working directories are created by the scripts under `data/raw/`, `data/processed/`, `data/extracted/`, and `data/metadata/`. These directories are ignored by Git because the source files remain available from their original repositories and some objects exceed normal GitHub file-size limits.

Do not apply the repository's MIT or CC BY licences to third-party source data. Consult the original NCBI records and associated publications for source-specific reuse terms.
