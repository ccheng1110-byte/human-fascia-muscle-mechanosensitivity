## Decision

No corresponding public GitHub files were identified. The article's statement
that original code “will be deposited at GitHub and be available online before
publication” is a stated availability intention, not evidence that the
repository is currently public or discoverable.

This result does not exclude a private repository, an unindexed repository with
an unrelated name, or code shared only by direct author link. The prepared
author request should therefore ask specifically for the GitHub URL or a
temporary repository/download link, in addition to the sample-resolved
processed object.
